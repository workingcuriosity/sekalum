What is an API token?

API tokens authenticate applications against Sekalum.

A scope describes the type of access requested by the token. Scopes come from the token configuration and are shown here so you can verify which scopes are used.

API token: authenticates a consumer against the HUB. Consumer grant: defines which credentials that consumer may use.
