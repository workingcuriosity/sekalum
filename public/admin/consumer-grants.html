What is a consumer grant?

A consumer grant is the administrator-approved connection between one consumer and one credential. It defines which named secret fields that consumer may use; it does not display or grant access to secret values beyond that selection.

Review the consumer, credential, provider, and granted fields together before changing a grant. Technical IDs are shown as additional context.

How consumer access works

This page explains the existing permission boundary. It does not change what the API or the Consumer may access.

The Consumer can see
Only active Credentials with a matching access entry, their public metadata, and the explicitly permitted Secret fields.

The Consumer never sees
Secret values that are not permitted, other Credentials, provider internals, or Management Token values.

Discovery and Resolve
Discovery returns the available Credential and field contract. Resolve returns only explicitly requested Secret fields allowed by this access entry; there is no wildcard access.

A Consumer API Token authenticates the Consumer. A Management Token is for administration only and is never a Consumer permission.
