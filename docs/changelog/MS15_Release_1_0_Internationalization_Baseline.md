# Release 1.0 Internationalization Baseline

## Added

- An English canonical Quick Start Guide.
- English-default Admin UI language resolution with German browser detection and an EN / DE switch.
- Shared browser-local language preference and translation catalogs for the scoped Admin pages.
- Safe localized fallback for unknown backend errors.

## Limitation

This release adds an English onboarding path and bilingual Admin UI baseline. It does not claim that the complete project documentation is bilingual.
