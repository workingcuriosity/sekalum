# Historical System Inventory

## Classification

This document is a sanitized historical record from the earlier Token Manager project phase. It is not a current installation, operations, configuration, or architecture source for Credential Hub.

## Historical Scope

The original record described a legacy deployment environment, runtime components, network exposure, persistence layout, configuration keys, provider state, commands, and documentation duties.

Installation-specific values, infrastructure details, environment variable names, ports, deployment paths, and legacy operating assumptions have been removed under DR-GOV-001.
